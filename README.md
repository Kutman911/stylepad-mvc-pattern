# Stylepad MVC Pattern
**StylePad MVC Pattern** — это полнофункциональный текстовый редактор для рабочего стола, реализованный на Java с использованием архитектуры **MVC (Model–View–Controller)** и библиотеки Swing для графического интерфейса.

---

## Требования

Перед запуском убедитесь, что у вас установлено следующее ПО:

- **Java JDK 17**
- **Atom**
- **Командная строка (CMD)** для запуска программы

---

## Установка и запуск

1. **Скачайте или клонируйте проект:**

   ```bash
   git clone https://labs.o.kg:3443/strategy-spring-pattern/stylepad-mvc-pattern.git
   cd stylepad-mvc-pattern

2. **Откройте проект в редакторе кода**

   В **Atom** или любом другом редакторе откройте папку проекта:  
   **File → Open Folder → выберите папку проекта**


3. **Проверьте установку JDK 17**

   Введите в терминале команду:

   ```bash
   java -version

4. **Скомпилируйте проект через CMD:**

   Введите в терминале команду:

   javac *.java

5. **Запустите приложение:**

   java Main

6. **После запуска появится главное окно текстового редактора с полным набором функций.**

## Структура проекта (MVC)

Проект реализован по паттерну **Model–View–Controller (MVC)** — архитектурному подходу, разделяющему логику приложения, пользовательский интерфейс и взаимодействие между ними.

---

### View

**Файл:** `Viewer.java`
Отвечает за **пользовательский интерфейс (GUI)**, построенный с использованием **Swing**.

#### Основные функции представления:

- Создает главное окно редактора (`JFrame`)
- Реализует текстовую панель (`JTextPane`) с поддержкой форматирования
- Создает меню (*File, Edit, Format, View*) с иконками и горячими клавишами
- Управляет статус-баром с информацией о количестве символов, кодировке и масштабе
- Обрабатывает диалоговые окна (шрифт, поиск, переход к строке)

#### Ключевые компоненты:

- `JTextPane` — расширенная текстовая область с поддержкой изображений  
- `JMenuBar` — панель меню с раскрывающимися списками  
- `JScrollPane` — область прокрутки для текста  
- **Статус-бар** — отображает статистику документа  
- **Диалоговые окна** — для выбора шрифта, поиска, печати

---

### Controller

**Файл:** `Controller.java`  
Отвечает за связь между **View** и обработкой пользовательских действий.


#### Основные функции контроллера:

- Реализует `ActionListener` для обработки событий меню
- Использует шаблон **Command** через `CommandHandler` и конкретные обработчики
- Управляет потоком выполнения приложения
- Координирует взаимодействие между компонентами


#### Архитектура команд:

- `CommandHandler` — абстрактный класс для всех команд
- Конкретные обработчики: `CopyHandler`, `SaveHandler`, `ZoomInHandler`, и др.
- `HashMap` команд для быстрого доступа к обработчикам

---

### Model

В отличие от классического MVC, моделью в этом проекте является файл


#### Функциональные модули:

- **Документ** — управляется через `JTextPane` и его `Document`
- **Настройки редактора** — шрифты, кодировка, видимость элементов
- **Обработка файлов** — чтение/запись через `FileHandler`
- **Печать** — через класс `PrintDocument`

---

### Основные функции

#### File Operations

- **New** — создать новый документ  
- **Open** — открыть существующий файл  
- **Save** — сохранить документ  
- **Save As** — сохранить под новым именем  
- **Print** — печать документа  
- **Open Image** — вставка изображений в документ  
- **Exit** — выход из приложения  


#### Edit Operations

- **Cut** — вырезать выделенный текст  
- **Copy** — копировать выделенный текст  
- **Paste** — вставить из буфера обмена  
- **Delete** — удалить выделенный текст  
- **Find** — поиск текста в документе  
- **Go To Line** — переход к определённой строке  
- **Select All** — выделить весь текст  
- **Time and Date** — вставка текущей даты и времени


#### Format Options

- **Wrap** — включение/выключение переноса строк  
- **Font** — выбор шрифта, стиля и размера  


#### View Options

- **Status Bar** — переключение видимости статус-бара  
- **Char Counter** — переключение счетчика символов  
- **Zoom In** — увеличение масштаба  
- **Zoom Out** — уменьшение масштаба  
- **Reset Zoom** — сброс масштаба к стандартному

---

### Дополнительные компоненты


#### **PrintDocument**  
**Файл:** `PrintDocument.java`

Реализует функциональность печати с поддержкой:

- Текста и изображений в одном документе  
- Автоматического разбиения на страницы  
- Масштабирования изображений под ширину страницы  
- Профессионального форматирования вывода  


#### **FindDialog**  
**Файл:** `FindDialog.java`

Диалоговое окно поиска с функциями:

- Поиск с учётом / игнорированием регистра  
- Поиск следующего вхождения  
- Циклический поиск по всему документу  


#### **GoToLineDialog**  
**Файл:** `GoToLineDialog.java`

Быстрый переход к определённой строке:

- Валидация вводимого номера строки  
- Проверка существования строки  
- Плавная навигация по документу  


#### **FontChooserDialog**  
**Файл:** `FontChooserDialog.java`

Расширенный выбор шрифтов:

- Просмотр всех доступных системных шрифтов  
- Выбор стиля (*Regular, Bold, Italic, Bold Italic*)  
- Выбор размера из предустановленных значений  
- Предпросмотр выбранного шрифта

### Особенности реализации

- **Чистая архитектура MVC** — чёткое разделение ответственности  
- **Шаблон Command** — для обработки пользовательских действий  
- **Профессиональный UI** — розовая цветовая схема с акцентами  
- **Расширенная функциональность** — поддержка изображений, печати, поиска  
- **Гибкие настройки** — масштабирование, выбор шрифтов, переключение элементов интерфейса  
- **Кроссплатформенность** — работает на любой системе с Java  

---

> **StylePad MVC Pattern** представляет собой учебный пример реализации полнофункционального текстового редактора с использованием современных паттернов проектирования и лучших практик Java Swing.
